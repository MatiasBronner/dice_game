Study links

Send each participant one link

Each participant plays twice in their group: session 1 (Set A) to learn the game with their group's help, then session 2 (Set B) with no help for anyone, to compare how well each group learned. Link 1 is for testing the game yourself.

The link decides the condition and the level set. Paths are numbered so participants can't tell which group they're in. Participants sign in with their first and last name, so everyone they play is linked to the same person, however many times you test them.

Each session: one practice level, then that set's 15 levels (5 easy, 5 medium, 5 hard) with the group's assistance. No quiz. Session 1: send the group's a link (2a, 3a or 4a). Session 2: send the same group's b link (2b, 3b or 4b). Hints are off in every b link; the adaptive and help-always groups are told there are no hints this time. Both sessions are linked to the same person by name.
Data goes to Supabase: participants (one row per person, with their name), sessions (with level_set = A or B), level_results, events. Use the Table Editor to view and export it. If a participant reloads the page, they can pick up at the level they were on.
